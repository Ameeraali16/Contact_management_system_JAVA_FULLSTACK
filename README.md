# Contact Management System (CMS)

## Overview
The Contact Management System (CMS) is a web-based application designed to help users manage their contacts. Users can register, log in, add, update, and delete contacts. Each contact can have associated phone numbers, emails, notes, and reminders.

## Features
- **User Registration & Authentication**: Users can create accounts and log in securely.
- **Contact Management**: Users can add, update, and delete contacts.
- **Contact Information**: Each contact can have multiple phone numbers, emails, notes, and reminders.
- **Search & Filter**: Contacts can be searched and filtered based on name, phone number, or email.
- **Responsive UI**: The application is fully responsive for use on different devices.

## Technologies Used
- **Backend**: Java, Spring Boot, PostgreSQL
- **Frontend**: HTML, CSS, JavaScript, React.js (or whatever tech you used)
- **Database**: PostgreSQL

## Installation

### Prerequisites
- JDK 11 or later
- Node.js (for the frontend)
- PostgreSQL

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/Contact_management_system_JAVA_FULLSTACK.git
2. navigate to backend folder, install dependencies and run:
   ./mvnw spring-boot:run
3. navigate to fontend folder and run:
   npm install
   npm start
